# 1.3.3　更强大的钓鱼手段

你是不是觉得自己像是在用消防水带喝水？信息量大得要将你淹没。人们用来窃取信息的手段之巧妙和过程之离奇真是让人难以招架。更糟的是，前面的例子只涉及了最基本的钓鱼攻击方式，还有更复杂（和令人沮丧）的方式。

我和克里斯把这些攻击方式按难度分类，是为了帮助客户理解他们所看到的东西，也是为了追踪客户的进步——能够识别越来越复杂的钓鱼攻击。第6章将会详细描述那些复杂的钓鱼攻击。
