# 个人评价

下面是我对PhishMe的评价。

+   - 使用这款工具需要怎样的知识水平？

由于PhishMe面向初学者或新手而开发，它很容易使用。设置任务十分容易。列表生成和定时任务界面都可以凭直觉操作。

上传名单也很容... 我在不太了解这款软件的情况下很轻松就找到了报告数据。布局和设计都是为新手准备的，能够很快上手。
