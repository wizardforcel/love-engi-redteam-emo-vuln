的确，图1-19中的钓鱼攻击做得很 好。如果这是一封克隆邮件，那么它就不会在语言、格式或者商标上存在问题，所以你需要做更多的调查。

+   - 检查链接，看它们指向哪里。（再次提醒，检查 并不是点击！）
+   - 确认发件人的邮箱地址是否与想要关联你的LinkedIn账户邮件地址一样。（要有批判性思维。）
+   - 如果你仍然不放心，那就忽略这封邮件，登录你的LinkedIn账户看看是否有邀请请求。
