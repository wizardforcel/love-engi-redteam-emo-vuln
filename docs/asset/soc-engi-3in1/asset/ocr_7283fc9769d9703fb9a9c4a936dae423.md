# 2. 演示性动作

1972年，艾克曼博士写了一篇名为《手部动作》²的论文。该论文将演示性动作定义为“那些与演讲、措辞、内容、声调的变化，以及声音响度等时时密切相关的行为”。

²Ekman, P. (1972, December). “Hand Movements.” Journal of Communication 22 (4), pp. 353 - 374.
