PhishLine（www.phishline.com）是一种企业级的SaaS解决方案，可模拟真实世界的社会工程学和钓鱼攻击，提供在线安全意识训练、基于风险的调查以及详细的报告和指标。

# 优点

+   - 多重渠道的攻击模拟 。 PhishLine并不限于传统的基于链接的钓鱼攻击模拟。它能够让用户对便携式媒体、文字、语音、模拟门户页面、智能附件等钓鱼攻击形式进行测试和衡量。同时它还支持一系列定制功能，允许安全专家精确地测试和衡量真实世界的安全威胁。
