不幸的是，安全专家的工作越来越多。我们发现只有少数组织机构愿意花钱在咨询或大型团队上，因此专业安全人员在这些公司里不得不身兼数职。显然，最好是由熟悉钓鱼攻击的人来进行钓鱼攻击培训和测试。但是即使这些你都没有，还有一些事情是你可以做的。

+   - 紧跟流行的钓鱼攻击方式，可以通过访问 [www.apwg.org](http://www.apwg.org) 和 [www.socialengineer.com](http://www.socialengineer.com) 这类网站。如果你仍然认为钓鱼攻击是一种由没受过什么教育的恶棍发起的低威胁性攻击，那么更新你在相关领域的知识可能是明智的。希望本书可以帮助你建立一些钓鱼攻击的基本概念。

+   - 把钓鱼攻击和普通社会工程学教育纳入你的安全意识培训中。你的工作一开始也许不能覆盖所有的情况，但通过这些方法来提醒你的员工总比希望问题自己消失要更好。

对钓鱼攻击的性质和范围有所了解后，你的最终目标是开展一系列连贯的课程，能够进行定期测试和培训，并教导所在的组织机构如何识别和应对现实生活中的钓鱼攻击。
