# 6.3.2　在日常生活中使用框架

参考框架是一组看法、条件或假设，它们决定了人们如何接近、认知或理解某一事物。这个定义有助于我们理解框架的运用方式。

任何可以用来改变人们的认知或者人们作决定的方式的东西都可以称为框架。朋友告诉你上周她去了镇上，由于一些地方在修路，她比平常多走了16千米。你可能会为了避免迟到而选择一条更远的路，即使朋友是在一个多星期以前告诉你这一消息的。
