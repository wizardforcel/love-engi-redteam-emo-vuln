# 7.2.3　基于电话的工具

社会工程书籍中最早介绍的工具之一就是电话。如今，随着手机、网络语音以及自制电话服务器的出现，社会工程人员使用电话的方式越来越多样。

社会工程人员需要熟练掌握电话的使用技巧以便进行成功的审查，因为人们经常会受到电话销售、推销和广告的骚扰。尽管有一些限制，但作为社会工程的工具，电话还是可以用来在短时间内搞定一家公司 的。
