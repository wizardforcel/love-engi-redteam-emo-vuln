+   - 用户信息的安全性如何？

+   - 使用该工具时有其他的困难吗？

+   - 技术支持如何？

# 7.2.2  Phishing Frenzy

Phishing Frenzy（[www.phishingfrenzy.com](http://www.phishingfrenzy.com)）是一款由Ruby on Rails构建的基于Linux的开源应用，也是渗透测试者用于管理钓鱼邮件攻击的工具。

# 优点

Phishing Frenzy的优点如下：

+   - 真正的弹性框架；
+   - 可以和Phishing Frenzy的其他用户共享模板和情景；
+   - 功能丰富，例如实时追踪、多任务并行处理，等等；
+   - 开源软件可以随意添加自己想要的功能。

# 缺点

+   - Phishing Frenzy只能在Linux上运行。
