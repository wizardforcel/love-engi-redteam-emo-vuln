# 别急着说“我不会被骗”，这句话恰恰是骗子的入场券

很多人对“安全”的想象，是一扇厚门、一把好锁、一套高级报警器，最好再加一条看门狗。可现实往往很扎心：钥匙忘带、门被反锁的那一刻，人才突然发现，原来漏洞一直摆在眼前。

安全这件事，站在门里和门外看，是两套逻辑。门里的人想要舒适、安心；门外的人却在琢磨怎么翻、怎么钻、怎么绕，甚至怎么大摇大摆走进去。问题是，太多人因为自信而看不见风险，觉得锁够结实、门够厚、系统够高级，就能把绝大多数人挡在外面。

保罗·威尔逊偏偏不属于“太多人”。

过去十年，他设计过的骗局多到超乎常人想象：在赌场让庄家吃亏，伪造体育赛事，操纵拍卖，诱骗别人交出心爱之物，还轻松进入过几个号称“牢不可破”的安全系统。他的工作，是在热门电视节目《骗术真相》中揭穿骗子、说谎者和各种套路。他和亚历克西斯·康兰每周一起做局，用隐藏摄像头记录受害者如何一步步上钩，再向观众演示同样的骗局该怎么识破。

这份工作让他对犯罪者的思路有了独特理解。他形容自己像一只披着狼皮的羊。以他的经验，再不可能的事情，也常常存在一种巧妙而意外的解法。

有个实验很能说明问题。

BBC 曾认为，让一位女士不仅丢钱包、还亲口说出信用卡密码，是不可能完成的任务，于是把选题退了回来。但栏目组知道这完全可能，因为英国各地已经出现过类似案件：受害者在精心设计的局里，主动把密码告诉了盗贼。他们从不同骗局中拆出关键要素，决定在伦敦牛津大街一个购物广场顶层的咖啡厅里真实演示一遍。

保罗穿着西装，提着公文箱，坐在相对安静的空桌旁等“猎物”。不久，一位女士和朋友坐到邻桌，把包放在旁边椅子上，手一直按着包。朋友去洗手间后，目标落单，保罗给亚历克斯和杰丝发了信号。两人扮成夫妻，请女士帮忙拍合影。她热心起身，手离开了包。就在她分神的瞬间，保罗把包拿进公文箱锁好。亚历克斯和杰丝离开咖啡厅后，迅速奔向停车场。

没过多久，女士发现包不见了，急得站起来四处找。保罗上前问是否需要帮忙，先安慰她坐下，再引导她回忆包里有什么：手机、化妆品、现金、信用卡。听说信用卡属于某家银行后，他立刻说自己正好是那家银行的员工，还保证“马上注销就没事”。他拨通“客服中心”，实际上接电话的是楼下面包车里的亚历克斯。车里用 CD 播放着从网上下载的办公室嘈杂声，听起来像真的客服中心。亚历克斯一步步取得信任，最后告诉她：注销很方便，但为确认身份，请在通话手机的键盘上输入信用卡密码。

手机是保罗的，键盘自然也在保罗手里。

密码到手后，保罗起身离开。如果他们是真小偷，接下来就可以用这张卡和密码取款、转账、消费。好在这是电视节目。当他把包还给女士并说明这是一场骗局时，对方竟然很开心，还向他道谢。保罗回答得很直接：“别谢我，包是我偷的。”

这说明什么？系统再安全，也总有被攻破的路径；而系统里的人，往往是最容易被欺骗和操纵的一环。制造紧张气氛、借势施压、操控节奏、先建立信任，都能让受害者慢慢放下戒备。一点小伎俩，就足以完成看似不可能的诈骗。

承认系统有漏洞，承认它可能被攻破，才是让系统更安全的第一步。反过来，那些坚信自己的系统绝对牢不可破的人，就像蒙着眼睛全速奔跑。社会工程学研究的正是系统中最薄弱的一环——人，以及如何利用人性攻破看似安全的系统。这本书不是黑客指南，因为黑客本来就知道怎么闯入系统，每天都在研究新方法。克里斯·海德纳吉要做的是，把世界上最险恶的黑客、骗子和社会工程人员的思路摊开，让普通人有机会从攻击者的暗面重新理解安全与防护。

防与攻的思维完全不同。进攻方会把翻越、钻入、绕行、穿越都试一遍，目标只有一个：进去。所以，你越笃定自己不会上当，越容易进入骗子的优先名单。

这本书的前言里，克里斯·海德纳吉讲了自己的故事。年轻时，他对“操控别人”很感兴趣，但不是为了干坏事，而是着迷于意外收获，着迷于把不可能变成可能。有一次，他和好友去纽约贾维茨会议中心参加技术会议。一家大公司包下施瓦茨玩具城办私人派对，只有持邀请函的客人能进，来宾多是惠普、微软等企业的高管，而他们只是两个小人物。朋友感叹：“能进去就太酷了。”克里斯却想：为什么不能？

他走到负责签到的女工作人员旁边聊了几分钟。这时，Linux 内核创始人林纳斯·托瓦兹走了过来。克里斯拿起一个带微软标志的长毛绒玩具，开玩笑地请林纳斯签名。林纳斯大笑着扬起票说：“不错嘛，年轻人，派对上见。”随后，克里斯转向验收邀请函的工作人员，竟然拿到了两张派对邀请函。

后来，他把这类经历称为“海德纳吉效应”。听起来像运气，其实不是命运偏爱，而是知道在正确的时间做正确的事。当然，努力和他人的帮助同样不可缺少。

他也把感谢写进了书里：感谢近 20 年来支持他的妻子，称她是最好的朋友、知己和支柱；感谢两个孩子给他继续前行的动力；感谢为网站付出数千小时的保罗（rAWjAW），感谢用创造力为网站添彩的汤姆（DigIp），感谢 Wiley 出版社编辑卡罗尔的统筹，感谢布莱恩在编辑会议上的真诚建议，感谢吉姆（Elwood）用持续核查让他保持谦逊严谨，感谢利兹在 12 年前建议他写书、陪他走过一段低谷，也感谢导师马蒂以及 BackTrack 和 offensive-security 团队的支持。封面上虽然只署了一个名字，背后却站着一群人。

爱因斯坦说过，信息并非知识。把书读完，知识不会自动长进脑子里；只有把原则用起来，把方法练成日常习惯，这些信息才真正有用。

所以，别把“我不会被骗”挂在嘴边。安全不是自信口号，而是一种持续换位、持续检查、持续补漏的能力。你越愿意从门外看自己，门里的世界才越稳。
