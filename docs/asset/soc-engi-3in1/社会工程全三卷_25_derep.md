# 第九章：非语言交流及社会工程师人类



> “我是谁并不取决于外表，而是由我的行为来定义。”

——布鲁斯·韦恩

在动笔写这本书之前，我心里已经搭好了一份目录，并把它交给了出版社作为主线框架。真正写下来后，成品和最初的设想几乎判若两物。研究在更新，案例在变化，我自己的认知也在写作过程中被不断重塑。

把这段经历写出来，是想先给社会工程师上一课。世界变化极快，唯有保持适应力才能存活。若人类丧失应变能力，迟早会被淘汰。

在剖析社会工程的恶意一面时，我反复看到适应力的作用。坏人总能快速学会新手段，搭上新技术。而在为企业做顾问时，我却常碰到抗拒改变的态度。“这么多年都这么做，为何要改？”这类话我听过太多遍。

世界从未停滞。骗子和窃贼一直存在，只是近年来冷漠型犯罪明显增多。打老人主意就是典型。无论老人体面与否，骗子会冒充亲友或官方机构，把他们身上最后的钱榨干。写这一章前一晚，我和朋友聊起这事。他说他朋友的母亲刚被同类骗局击中。那位老太太已是癌症晚期，存款不多，骗子却不放过，几通电话就把钱卷走。

旁人关怀的淡化，加上邮件、电话、网络身份信息被轻易窃取，让恶意社会工程更有可乘之机。

在工作和生活中，我们能用软件、流程抵御恶意代码、病毒和木马，能换更结实的锁、装更灵敏的报警，甚至雇人盯梢征信报告。但面对人性操纵，却缺乏工具和系统。骗子只要让你点一下转账、报一下卡号，现有的技术就无能为力。

这不代表无望，只是修复成本很高。正因为如此我才写了第一本书，也写了这本：先弄懂，再行动，知行合一才是防线。

正如大多数事一样，第一步是理解。要搞清攻击如何发生、用哪些手法、表现怎样、目标是什么。

有了认知，后续就是行动，也就是防护措施。知识是抵御黑客和社会工程师的唯一真正屏障。能察觉端倪，听懂话里话，甚至捕捉言外之意，就有了防御的机会。

最后一章我会从两个角度展开。一是作为渗透测试者如何把知识落地，用实战演练提升客户防护能力。二是把本书作为防御手册来用。无论你是 IT 同事、讲师、家长还是普通公民，都能藉此提升沟通力，判断对方是否在设局。

### 9.1 像社会工程师一样运用信息

我开设的五天“渗透测试人员社会工程”课程，核心口号是让每一个接触到你的人都觉得相遇是件好事。目标是在五天内教会学员搜集个人信息的技巧，诱导的前提是绝不强迫、绝不让人不适。最终我更在意的不是信息本身，而是学员的成长。有学员说这门课改变了他的生活，教他如何成为更好的丈夫和父亲。为什么会这样？因为社会工程本质是沟通的艺术。当你努力让交流对象因你而感到更好时，生活也会随之改变。

课程里有一节格外不同——“恶意社会工程师用的是同一套方法”。这节课的冲击往往在结束很久后才显现。

我曾在播客 www.social-engineer.org 采访过催产素研究专家保罗·扎克博士，节目可在 www.social-engineer.org/ep-044-do-you-trust-me/ 查阅。催产素是在我们感受到信任、联结和亲密时分泌的分子。除了哺乳，它在我们与信赖之人交流时也会大量释放。扎克博士还讲过自己年轻在加油站打工的经历。两个骗子用“放鸽子”手法骗了他。那天一个男人拿着小盒子走进办公室，说是在洗手间捡到的，里面似乎有贵重珠宝。正当保罗思考对策时电话响了，对方急切描述珠宝丢失经过。保罗告诉他此刻正有一位诚实的顾客把盒子交上来。对方欣喜表示愿付 200 美元酬谢。挂断后，保罗告诉捡盒者主人会给报酬。捡者说还要去面试，得先走，提议两人平分报酬，保罗先从收银机拿 100 美元给他，等主人来后再拿 100 美元给自己，剩 100 美元放回收银机。

保罗给了钱，主人却没出现，100 美元就这样没了。扎克博士的解释是：骗子成功并非因为说服你相信他，而是让你觉得他相信你。当人感到被信任，大脑会分泌催产素。情绪一旦卷入，边缘系统占上风，逻辑便被压制。

对社会工程师而言这是关键点。当对方感觉你信任他时，他会以信任回馈。我的学员们学到的正是这一点：善良和信任的外衣下藏着骗术，而人往往会被蒙住很久。

首本书出版后，我收到很多采访邀约，其中一个问题让我警觉：“你不怕教会坏人吗？”我的回答从未改变：若不懂进攻，防守就无从谈起。第一次实战挨打，代价通常很惨。人们学格斗就是为了学会打、挨打和自保。课堂上会实打实地对练。

渗透测试同理，要学会承受、施加和抵御。想打拳王争霸赛，不会去街头找瘦弱新手陪练，会找技术、体重和经验相当的陪练。渗透测试的陪练该是什么样？是新手还是能帮你备战的对手？

迈克菲前副总裁德米特里·阿帕洛维奇说过的话更让我坚定：“我相信所有拥有重要知识产权和商业机密的大公司都缺乏抵御能力，或很快会缺乏，且绝大多数受害者从未察觉入侵。”

坏人不会去书店买《如何做坏人》，他们在实战中学习。我们却有资源去学习防御。

因此在动笔前，我用了两年多时间与艾克曼博士和保罗·凯利建立深度合作。两位大师帮我大幅缩短学习曲线。跟大师同行，能吸收他们的技艺、知识，更重要的是经验。

理解骗子的伎俩耗时耗力。我每周阅读大量最新攻击报告和行为研究，这正是我的工作：尽力保护客户。你的工作、家人和生活可能并不安全，本书想提供一条便捷路径，让你练习并落地这些技能。

先放下安全话题，专注沟通。无论是孩子、伴侣、上司、学生，还是商店、教堂、街头遇到的陌生人，运用这些技巧你会成为更好的沟通者，信息的发出与接收方式都会改变。

在他人沉默时读懂真实意图，能改变沟通风格，更有效地传递信息。若把这些能力用于搭建安全屏障，不仅沟通更顺畅，还能捕捉对方无明确目标时的细微线索。

学会后，请把它纳入安全识别流程。让同事明白恶意社会工程师如何使用这些技巧，培养批判性思维，让他们意识到多问一句能带来多大差异。

### 9.3 成长为批判性思考者

2012 年夏天我读到一篇报道，德克萨斯州共和党在官方平台上反对公立学校教授批判性思维。有人竟想禁止最基础的技能教学，让人震惊。

批判性思维常被误读为叛逆、信仰缺失或为问而问。我非此意。我信仰坚定。严格说来，我像个典型的“黑客”，喜欢走捷径、拆解原理，但并非真叛逆。我尊重法律与秩序。

我对批判性思维的定义是：不要让自己、家人、员工和客户被表象牵着走。不要盲目相信来人是废弃物管理员、职业安全检查员、IT 人员乔，或某公司副总裁助理。若情况不明、来电陌生、请求异常，就要质疑。

批判性思维需要时间，有时还有风险。我曾合作的一家公司大量使用呼叫中心客服，有个奇葩政策：通话超两分钟，代表的时薪就按超时扣减。知情后，我打电话时故意拖过两分钟。代表开始焦虑，想尽快结束以保工资。这时我提出敏感要求，焦虑让他停止批判思考，开始答题。当我轻声说“我不想耽误您太久，就最后一个问题”时，对方更想结束通话，随后我会问：“我自己做点小生意，想成熟点。您觉得哪家清洁公司靠谱？”或“我刚开办公室，不知道用啥系统，您用啥操作系统？啥浏览器？”

通话临近尾声，代表已无法正常推理，只想保住工资，于是做出糟糕决定，泄露不该说的信息。

若企业推崇批判性思维，让员工在质疑后阻止攻击并保护公司资产时得到奖励，局面会良性发展。反之，太多公司按是否照章办事来奖惩。

为帮助客户培养批判性思维，我设计了“批判性思维入门”练习。它不是话术，而是一套思考习惯。以下是以自动取款机为例。

1. 先环顾四周，确认安全。
2. 走到机器前再拿卡。
3. 插卡前晃动卡槽，确认是机器一部分而非伪装读卡器。
4. 注意突兀或异常部件，那可能是窃取信息和密码的装置。
5. 输入密码时遮挡键盘。
6. 取款后带齐现金、卡和收据。
7. 离开时把物品放回钱包。

这些简单步骤可避免伪造部件带来的损失。帮助员工或客户为各种场景建立入门程序。

- 怀疑邮件是钓鱼时怎么办？
- 点到可疑链接后该如何处理？
- 怀疑电话是钓鱼时怎么办？
- 怀疑对方身份不符时怎么办？
- 不该回答却已回答问题后该如何补救？

如果公司对员工收到钓鱼邮件的反应是惩罚，挑战会更大。员工不敢公开讨论安全疑虑。管理层要认识到，被骗不是软弱或愚蠢，是人之常情。应帮助员工止损、降低副作用。最佳做法是设立专门的报告与安全事件部门或专员，不因上报而受罚，并可提供额外培训。

### 9.4 总结

写作本书的过程也是学习过程。与艾克曼博士和保罗·凯利的深度合作改变了我对非语言行为的理解和运用。学习越多，日常交流中捕捉到的信号越多，沟通更宽广、理解更深、也更安全。本书没有神奇技能让你变身测谎专家或读心者，但结合书中技能，你能真正理解对方的情绪表达，即便他一句话没说。这是一种奇妙的能力。

练习时请记住艾克曼博士的提醒：“能看出别人的感受，不等于知道他为何有这种感受。”这是我入行初期得到的教诲。学习把观察到的情绪用于引导，关注基准态的细微变化。无论是否为专业社会工程师，这些技能都能提升沟通力。

想讨论相关话题或对书中观点展开辩论，欢迎联系我。网址是 www.social-engineer.com，上面有直接交流的方式。随时欢迎切磋。

感谢你花时间阅读本书。希望你能获得可用于生活的实操信息，因为我的生活一直因此受益。

最后，请记住我的信条：让人们因为遇见你而感觉更好。有人靠羞辱和恐惧达成目的，有人用嘲笑来“教育”。我相信谦逊、善良和鼓励会带来更好结果。批判性思维也一直在帮助我。无论对方是孩子还是像孩子一样，愿我们能花时间从他的眼里看见问题，花时间去理解情绪，无论它是否合理。我保证，当你这样做时，一个全新的世界会向你展开，你可以洞察社会工程师，甚至任何站在你面前的人的秘密。

## 小白要批判，专家要灵活

### 社会工程专家 Christopher Hadnagy 访谈

Christopher Hadnagy 在计算机技术领域深耕 14 年，如今专注于信息安全中的“人”因素研究。他创立了全球首个社会工程框架 Social-Engineer.Com，帮助企业提升安全并教授“坏人手法”。他研究并破解了众多恶意攻击，推荐的实战演练法被 500 强企业采用。他与 BackTrack 安全团队合作多年，拥有近 20 年安全与信息技术经验，也是 Offensive Security 渗透测试小组的培训师和首席社会工程专家。著有《社会工程：安全体系中的人性漏洞》《社会工程 卷 2：解读肢体语言》《社会工程 卷 3：防范钓鱼欺诈》等。

**图灵社区：** 哪起事件让公众开始重视社会工程？

Chris：在过去一年半里，全球商业领域超过 60%的重大攻击主要手段都是社会工程。

**图灵社区：** 你如何进入信息安全领域？这个领域对普通人和程序员都显得很神秘。

Chris：我擅长与人交流，也热爱计算机和安全研究。从学习心理学起，一切水到渠成。社会工程就是研究如何影响和操纵他人，让其做出不该做的事。

**图灵社区：** 为何决定专注信息安全中的人性因素？

Chris：我喜欢对话。坏人仅凭谈话就能左右别人，他们怎么做？研究非语言交流也让我着迷。

**图灵社区：** 培训非安全专业人员时最大的挑战是什么？

Chris：最难的是培养批判性思考。这不像软件 1+1=2。对人而言，一加一未必等于二，关键是理解概念而非死守规则，灵活运用概念才是根本。

**图灵社区：** 社会工程成功的关键因素？

Chris：灵活和投入。无论环境如何都能随机应变，全程专注，即使失误也能大幅提高成功率。

**图灵社区：** 信息安全必须被动部署吗？是否只有攻击后才升级？

Chris：不是。安全应始终在线。若第一次打击就是实战，必败无疑。必须常态化测试、复盘、甚至“挨打”，才能知道被攻击时如何反应。

**图灵社区：** 白帽与黑帽永远对抗，如何保持领先甚至先发制人？

Chris：这是全职工作。我们必须持续阅读、研究、尝试新事物，投入极大。

**图灵社区：** 如今黑客转向硬件，如远程控制汽车、让 ATM 吐钱。社会工程在硬件黑客中重要吗？

Chris：很重要。很多案例都始于一通电话或一封钓鱼邮件。

**图灵社区：** BackTrack 对学习黑客技术有何优势？

Chris：BackTrack 及后来的 Kali Linux 内置了完整的渗透测试工具，是学习黑客技术的最佳系统。

**图灵社区：** 早期创业者融资时常更毛躁，对他们有何防社会工程建议？

Chris：

- 运用批判性思考，不要对“好消息”反应过度；
- 记住社交媒体上公开的一切都可能被用来不利；
- 一通电话或一封邮件就足以让你沦为受害者。

（译者：李盼）

网络安全从来不只是防火墙和杀毒软件的事。图灵数字版《社会工程：防范钓鱼欺诈（卷 3）》把视角对准了“人”这一环：攻击者如何利用心理弱点让人点下链接、交出信息，防御者又该如何识别、训练和应对。本书作者为 [美] Christopher Hadnagy、Michele Fincher，译者是肖诗尧，ISBN 为 978-7-115-43547-7，由北京图灵文化发展有限公司发行数字版。

**全书脉络速览**

第一章把镜头拉到真实世界：先讲网络钓鱼的基础知识，再说明人们通常怎样实施钓鱼，随后用案例展开——从重大攻击事件，到常见手法、更进阶的手段，以及鱼叉式网络钓鱼，最后收束总结。

第二章拆解决策背后的心理机制：认知偏差、生理状态、外部因素和决策底线都会左右判断；书中也解释为何人容易“当局者迷”，钓鱼攻击者又是怎样让目标咬钩的。关于杏仁核，既谈到“杏仁核劫持”，也讨论如何控制它；并用“清洗、漂洗、重复”概括反复施加影响的过程。

第三章聚焦影响与操控：先说明两者为何需要区分，再讲识别方法，包括如何与目标建立融洽关系、目标发现自己被测试时会有何感受、测试意图是什么。接着剖析操控的恶意本质、谎言以及惩罚与操控。影响原则是重点，共八条：互惠、义务、妥协、稀缺、权威、一致性与承诺、喜爱、社会认同。章末还补充社会性、生理反应、心理反应，以及关于操控必须知道的事。

第四章给出五堂保护课：第一课是批判性思维；第二课是学会悬停，并回答点击链接后感觉危险该怎么办；第三课是 URL 解析；第四课是分析邮件头；第五课是沙盒。每一课都专门提示“攻击者是如何绕过防御的”。书里还拆穿“绵羊墙”式坏主意陷阱：以为复制粘贴就能解决麻烦、认为分享也是关照、觉得移动设备一定安全、迷信好的反病毒软件可以拯救一切。

第五章讲企业如何规划钓鱼攻击旅程、开展项目：基本方法包括为什么做、主题是什么、邮件中要不要使用商标；培训落地则覆盖设定基线、设定难度、编写钓鱼攻击邮件、追踪和统计、报告，以及“钓鱼攻击、教育、重复”的循环。

第六章审视公司政策中积极、消极和“丑陋”的一面：跟着感觉走会让情绪影响政策；还有“老板是例外”“我只会修补其中一个漏洞”“太多训练使人厌倦”“如果发现钓鱼攻击，请打这个电话”“坏人在周一休假”“眼不见心不烦”等误区。每项都从定义、消极之处、如何改进三方面展开，最后提炼给所有人的经验。

第七章介绍专业钓鱼攻击者的工具包：商业应用包括 Rapid7 Metasploit Pro、ThreatSim、PhishMe、Wombat PhishGuru、PhishLine；开源应用包括 SET、Phishing Frenzy；另有对比表格，并讨论“谁来管理培训”。

第八章回到管理者视角：像老板一样进行钓鱼攻击，需要知己知彼、为组织机构设定合理目标、规划培训项目、理解指标、适当回应，并在决定时刻判断是内部构建还是外部构建。
