# 卷三：防范钓鱼攻击

# 卷三｜别让一条假链接钓走你的信息

这一卷，我们聊聊如何识别并避开网络钓鱼。

网络钓鱼往往不会明晃晃地说“我是骗子”，而是把自己包装成一封紧急邮件、一条客服短信、一个看似熟悉的登录页面，甚至是一份“限时福利”。它利用的是人的信任、好奇和着急，一旦你点了链接、填了账号密码或验证码，信息就可能落到别人手里。

想少踩坑，记住几个动作：陌生链接先别点，尤其是催你立刻处理的；对方身份先核实，别只看来电显示和头像；密码、验证码、银行卡信息不轻易交给任何人；遇到可疑页面，关掉并从官方渠道重新进入。平时给账号加上双重验证，也能多一道保险。

网络钓鱼防的不是“我肯定不会上当”，而是每一次点击前的多一秒犹豫。卷三的重点很简单：看清套路，守住账号，也守住钱袋。
