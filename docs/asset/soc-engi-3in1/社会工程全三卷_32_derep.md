# 第六章：积极的、消极的和丑陋的：公司政策及其他



说实话，政策并不是个讨喜的话题，没人愿意把大把时间耗在写一堆大家都要遵守的规则上。但想让公司更安全、让员工有明确的行动准则，政策是不可或缺的。

再强调一次：我清楚，推行我提议的这些安全政策，需要花费大量的时间、精力和财力，也肯定不轻松。这个过程可能很漫长，路上也会有不少坎儿。但别因为这些就放弃。坚持往前推进，最终的结果会向你证明——你投入的每一分心力、每一块钱，都是值得的。

我之前合作过的一家公司，钓鱼邮件点击率从 80%降到了 9%，而报告率却从不足 10%攀升到 64%。他们的恶意软件事件数量，也比过去减少了整整七成。靠的是什么？就是这些新政策扎实落地。

这些变化是一夜之间发生的吗？当然不是。他们花了几年时间才走到这一步。但回头看看，难道不值得吗？只有依靠持续不断的钓鱼模拟测试、规律培训和反复努力，才能换来这样的成绩。

培训刚启动的时候，我们也见过不少公司，眼睛只盯着数字不放。但请记住，培训的核心目标是让员工真正理解钓鱼攻击的风险，同时也让管理者看到培训带来的改变。数据有时候会让人迷失，太关注统计，反而容易忽略人本身和最终的目标。

不幸的是，现实中确实有很多公司过度沉迷于数据，背离了员工的真实需求，最后只剩下一堆“漂亮”的数字撑场面。请认认真真执行你的培训项目，时刻提醒自己：你的目标，是让报告的人变多、点击的人变少。这也许需要时间，但靠“编数字”永远无法让员工真正成长。
